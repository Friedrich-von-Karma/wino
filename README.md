# Gryf i Winorośl — System Zarządzania

System ERP dla dystrybutora wina — import/eksport, magazyn, klienci, finanse, dokumenty celne.

## Funkcje

- 📊 **Dashboard** — KPI, wykresy sprzedaży, alerty
- 📤 **Import Excel/CSV** — wczytywanie danych z plików
- 🍷 **Magazyn wina** — stany, marże, alerty min.
- 📦 **Zamówienia** — śledzenie statusów, SAD
- 💰 **Finanse** — P&L, faktury VAT, koszty
- 👥 **Klienci & Dostawcy** — baza kontaktów
- 📄 **Certyfikaty** — wg dostawców (EUR.1, lab, DOC)
- 🚛 **Dokumenty celne** — SAD/CMR wg zamówień
- 📋 **Licencje & Akcyza** — terminy ważności, rozliczenia
- ✅ **Zadania** — alerty, terminy, aktywność
- 📈 **Raporty** — eksport danych

## Uruchomienie

```bash
npm install
npm run dev
```

## Technologie

- React 18
- Vite
- Chart.js
- SheetJS (XLSX)
- Tabler Icons

## Wdrożenie

Projekt skonfigurowany do automatycznego wdrożenia na Vercel.
